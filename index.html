    Methodology

    Method & analysis

    A short methodology note on how a quote becomes a validated surface, and the conventions the analysis runs on: volatility is decimal (0.60 = 60%), maturity \(T\) is in years on ACT/365, log-moneyness is \(k=\ln(K/F)\), and total variance is \(w(k,T)=\sigma^2(k,T)\,T\). Each step below states what it assumes and how it is checked; full derivations live in the repository under docs/derivations/.

    01 · PRICING

    Black-76, futures-settled European option

    \[ C = e^{-rT}\big[F\,\Phi(d_1)-K\,\Phi(d_2)\big],\qquad d_{1,2}=\frac{\ln(F/K)\pm\tfrac12\sigma^2T}{\sigma\sqrt{T}} \]

    Crypto options settle against a futures/forward, so the forward — not spot — is the pricing state variable. Implied vol inverts this for \(\sigma\) by Newton on vega with a bracketed fallback, which keeps the root inside \(\sigma\in(0,5]\).

    02 · FORWARD

    Forward extraction by put–call parity

    \[ C(K)-P(K)=e^{-rT}\,(F-K) \]

    Regressing \(C-P\) on \(K\) across paired strikes recovers the slope \(-e^{-rT}\) and hence the discount factor and forward, per expiry — no constant-rate or zero-basis assumption. The live panels above use Deribit's published per-expiry underlying_price as \(F\); the library derives it from the quotes.

    03 · SMILE

    Raw SVI slice

    \[ w(k)=a+b\Big(\rho\,(k-m)+\sqrt{(k-m)^2+\sigma^2}\Big) \]

    Five parameters per expiry, fitted with the Zeliade quasi-explicit scheme: an outer search over \((m,\sigma)\) wrapping an inner constrained least-squares solve for \((a,b,\rho)\). The surface plotted above is a non-parametric local-quadratic smoother on \(w\) — the same input the SVI fit consumes, shown before parameterisation.

    04 · BUTTERFLY

    Density non-negativity, \(g(k)\ge 0\)

    \[ g(k)=\Big(1-\frac{k\,w'(k)}{2w(k)}\Big)^{2} -\frac{w'(k)^2}{4}\Big(\frac{1}{w(k)}+\frac14\Big)+\frac{w''(k)}{2} \]

    Evaluated numerically over a stated domain (e.g. \(k\in[-2,2]\), 1001 points) and cross-checked against the Breeden–Litzenberger density \(\partial^2C/\partial K^2\ge 0\). Reported with its tolerance: a pass is evidence over that grid, not a proof over the whole real line.

    05 · CALENDAR

    Calendar monotonicity & SSVI

    \[ \partial_T\,w(k,T)\ge 0,\qquad w(k,\theta)=\frac{\theta}{2}\Big(1+\rho\varphi(\theta)k+\sqrt{(\varphi(\theta)k+\rho)^2+1-\rho^2}\Big) \]

    SSVI ties the slices together through the ATM total variance \(\theta(T)\) and a \(\varphi(\theta)\) family. Gatheral–Jacquier give parameter conditions that make the surface free of calendar and butterfly arbitrage; VolFoundry enforces them during calibration rather than only auditing afterwards.

    06 · HYGIENE

    What gets thrown away first

    \[ \text{keep } q:\;\; b>0,\;\; a>b,\;\; \tau > \tau_{\min},\;\; \max(F-K,0)e^{-rT} \le C \le Fe^{-rT} \]

    Zero-bid, crossed and stale quotes, sub-day maturities and prices outside the static no-arbitrage bounds are removed before inversion, and the counts are reported. A surface is only as honest as the quote filter under it.

    Use it as a library

    Pure Python, typed, tested against analytic cases and reference surfaces. Same code path the panels on this page are modelled on.

    shell
    # install
$ pip install volfoundry

# live chain → calibrated, validated surface
$ volfoundry live --currency BTC --out surface.json

# or from Python
>>> from volfoundry import Chain, SSVISurface
>>> chain   = Chain.from_deribit("BTC")
>>> surface = SSVISurface.calibrate(chain)
>>> surface.validate(domain=(-2, 2), n=1001).is_valid
True
>>> surface.iv(k=0.0, T=30/365)
0.5812
