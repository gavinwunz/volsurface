    Methodology

    Pricing, calibration & no-arbitrage validation

    The pipeline that turns a raw quote into a validated surface, with each step tied to its source in the literature and to where it runs in the code. Conventions: volatility is decimal (0.60 = 60%), maturity \(T\) is in years on ACT/365, log-moneyness is \(k=\ln(K/F)\), and total variance is \(w(k,T)=\sigma^2(k,T)\,T\). Full derivations are in the repository under docs/derivations/; numbered references are listed below.

    01 · PRICING

    Forward-settled European options [1]

    \[ C = e^{-rT}\big[F\,\Phi(d_1)-K\,\Phi(d_2)\big],\qquad d_{1,2}=\frac{\ln(F/K)\pm\tfrac12\sigma^2T}{\sigma\sqrt{T}} \]

    Black's forward measure [1]: crypto options settle against a future, so the forward — not spot — is the state variable. In VolFoundry: pricers.black76_price evaluates this; iv.implied_volatility inverts it for \(\sigma\) by Newton on vega with a bracketed (Brent) fallback, holding the root in \(\sigma\in(0,5]\).

    02 · FORWARD

    Forward curve from put–call parity

    \[ C(K)-P(K)=e^{-rT}\,(F-K) \]

    A model-free identity. Regressing \(C-P\) on \(K\) across paired strikes yields slope \(-e^{-rT}\), hence the discount factor and forward, per expiry — no constant-rate or zero-basis assumption. In VolFoundry: SurfaceBuilder runs this regression; the live panels above use Deribit's per-expiry underlying_price as \(F\).

    03 · SMILE

    SVI slice parameterisation [3][6]

    \[ w(k)=a+b\Big(\rho\,(k-m)+\sqrt{(k-m)^2+\sigma^2}\Big) \]

    Gatheral's stochastic-volatility-inspired form [3]; its wing slopes \(b(1\pm\rho)\) obey Lee's moment bound \(\le 2\) [5]. In VolFoundry: svi.calibrate_svi_slice uses the Zeliade quasi-explicit scheme [6] — outer search over \((m,\sigma)\), inner constrained least-squares for \((a,b,\rho)\).

    04 · BUTTERFLY

    Butterfly arbitrage: the \(g(k)\) condition [4]

    \[ g(k)=\Big(1-\frac{k\,w'(k)}{2w(k)}\Big)^{2} -\frac{w'(k)^2}{4}\Big(\frac{1}{w(k)}+\frac14\Big)+\frac{w''(k)}{2}\;\ge\;0 \]

    Non-negative risk-neutral density in Gatheral–Jacquier form [4], cross-checked against the Breeden–Litzenberger density \(\partial^2C/\partial K^2\ge 0\) [2]. In VolFoundry: arbitrage evaluates \(g(k)\) over a stated domain (e.g. \(k\in[-2,2]\), 1001 pts) at a reported tolerance — evidence over that grid, not a proof over the whole real line.

    05 · CALENDAR

    Calendar arbitrage & the SSVI surface [4]

    \[ \partial_T\,w(k,T)\ge 0,\qquad w(k,\theta)=\frac{\theta}{2}\Big(1+\rho\varphi(\theta)k+\sqrt{(\varphi(\theta)k+\rho)^2+1-\rho^2}\Big) \]

    SSVI couples the slices through ATM total variance \(\theta(T)\) and a \(\varphi(\theta)\) family; Gatheral–Jacquier give the parameter conditions for a calendar- and butterfly-free surface [4]. In VolFoundry: strict validation enforces these during calibration and rejects violating fits, rather than auditing after the fact.

    06 · FILTERING

    Quote filtering & no-arbitrage bounds

    \[ \text{keep } q:\;\; b>0,\;\; a>b,\;\; \tau > \tau_{\min},\;\; \max(F-K,0)e^{-rT} \le C \le Fe^{-rT} \]

    Zero-bid, crossed and stale quotes, sub-day maturities and prices outside the static no-arbitrage bounds are removed before inversion. In VolFoundry: the data layer records per-reason drop counts so the surface is auditable — a fit is only as sound as the quotes beneath it.

    Use it as a library

    Pure Python, typed, tested against analytic cases and reference surfaces. Same code path the panels on this page are modelled on.

    shell
    # install
$ pip install volfoundry

# live chain → calibrated, validated surface
$ volfoundry live --currency BTC --out surface.json

# or from Python
>>> from volfoundry import Chain, SSVISurface
>>> chain   = Chain.from_deribit("BTC")
>>> surface = SSVISurface.calibrate(chain)
>>> surface.validate(domain=(-2, 2), n=1001).is_valid
True
>>> surface.iv(k=0.0, T=30/365)
0.5812
